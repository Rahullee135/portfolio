## ✨ Features

- 🎯 **Custom Cursor** — Smooth animated cursor with hover effects
- ✨ **Particle Background** — Interactive floating particles with connections
- 🎬 **Loading Animation** — Branded code-style loader
- 📱 **Fully Responsive** — Mobile-first design
- 🎭 **Framer Motion** — Scroll-triggered animations throughout
- 🪟 **Glassmorphism** — Modern frosted glass UI elements
- 📐 **Micro-Frontend Architecture** — Modular component structure
- 🌙 **Dark Theme** — Developer-friendly dark mode

## 🏗️ Architecture

```
src/
├── components/           # Micro-frontend modules
│   ├── CustomCursor.jsx      # Animated cursor
│   ├── ParticleBackground.jsx # Canvas particles
│   ├── Loader.jsx            # Loading screen
│   ├── Navbar.jsx            # Navigation with scroll-spy
│   ├── Hero.jsx              # Landing section
│   ├── About.jsx             # About me
│   ├── Skills.jsx            # Tech stack grid
│   ├── Experience.jsx        # Timeline
│   ├── Projects.jsx          # Project cards
│   ├── Contact.jsx           # Contact form
│   └── Footer.jsx            # Footer
├── styles/
│   └── App.css               # Global styles
├── App.jsx                   # Root component
└── main.jsx                  # Entry point
```

## 🚀 Setup

```bash
npm install
npm run dev
```

Open **http://localhost:5173**

## 📦 Build

```bash
npm run build
```
